## Selected Work

### Context Prism

[Context Prism](https://github.com/stefanimp/context-prism) is an open-source Obsidian plugin that turns local notes into compact context packs for AI assistants.

It focuses on:

- local-first retrieval from Markdown notes;
- TF-IDF and BM25-style lexical ranking;
- multilingual vault support;
- explainable candidate selection;
- token-aware context packs for tools such as ChatGPT, Claude, Codex and Cursor;
- privacy: no telemetry, network calls or external AI dependency.

Tech stack: TypeScript, Obsidian API, testing, documentation and release automation.

### Obsidian Second Brain Starter

[Obsidian Second Brain Starter](https://github.com/stefanimp/obsidian-second-brain-starter) is a practical starter system for building privacy-safe Obsidian vaults with MOCs, templates, properties and review workflows.

It reflects my interest in structured knowledge work, developer tooling and systems that make information easier to retrieve and reuse.
